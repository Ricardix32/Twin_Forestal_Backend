# ECMWF ERA5-Land Reanalysis Directory

Coloca aquí las series meteorológicas diarias o mensuales descargadas de Copernicus CDS:
* **Formato soportado:** `.csv` o `.nc` (NetCDF)
* **Variables:**
  * Temperatura a 2m (`2m_temperature` -> `tempC`)
  * Precipitación total (`total_precipitation` -> `precipMm`)
  * Déficit de presión de vapor (`vpdKPa`)
  * Radiación solar superficial (`surface_solar_radiation_downwards` -> `radMJm2`)
